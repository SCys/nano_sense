# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a FastAPI-based AI services API providing four main endpoints:
- Audio transcription (ASR) using FunASR
- Text-to-speech (TTS) using Qwen3-TTS-ONNX
- Text embeddings via OpenAI-compatible API
- Object detection using YOLO (Ultralytics)

The API is designed for GPU-accelerated inference with automatic model unloading after idle timeouts.

## Architecture

### High-Level Structure

```
src/
├── main.py              # FastAPI app, router registration, entry point
├── config.py            # Config class: loads TOML, env var overrides
├── globals.py           # ModelManager (lazy-load + auto-unload), model getters
├── api_*.py             # Route modules (transcriptions, synthesis, embeddings, vision)
├── Dockerfile           # Multi-stage build (deps-builder + PyTorch runtime)
├── pyproject.toml       # Dependencies (uv)
├── main.toml            # Configuration (primary)
├── main.ini             # Configuration (legacy)
├── run_tests.py         # Test runner
└── test_*.py            # Test files (some use mocks)
```

### Key Patterns

**Model Management (globals.py)**
- `ModelManager` wraps model loaders with lazy initialization and idle-timeout unloading.
- Access models via `get_*()` functions (e.g., `get_asr_recognizer()`, `get_vision_model()`).
- Timeout configured per model in `main.toml` (e.g., `[asr].timeout_seconds`).
- Unloading calls `gc.collect()` and `torch.cuda.empty_cache()` for GPU memory.

**Configuration (config.py)**
- Primary: `main.toml` parsed with `tomllib` (Python 3.11+) or `toml` fallback.
- Sections: `[asr]`, `[ultralytics]`, `[openai]`, `[tts]`, `[general]`.
- Environment variables override TOML: `ASR_MODEL_PATH`, `ULTRA`...
